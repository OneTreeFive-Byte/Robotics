🤖 Arduino Uno

Placa de hardware libre basada en el microcontrolador ATmega328p. Estándar mundial educativo.

  • ▸ 14 pines digitales (6 con PWM)
  • ▸ 6 entradas analógicas
  • ▸ Alimentación: 5V / 3.3V
  • ▸ Comunicación: USB, I2C, SPI
  • ▸ Lenguaje: C/C++ simplificado

🧩 Scratch

Lenguaje visual del MIT. Programa arrastrando bloques — sin errores de sintaxis.

  • ▸ Ideal para iniciar en pensamiento computacional
  • ▸ Integrable con Arduino: S4A / PictoBlox
  • ▸ Crea juegos, animaciones y controla el mundo físico
  • ▸ Sin instalación — funciona en el navegador

// SENSORES & CONEXIONES センサー

📌 Regla general: Todos los sensores comparten: VCC → Alimentación · GND → Tierra · SEÑAL → Pin de lectura

📏 HC-SR04 — Distancia

VCC → 5V · GND → GND · Trig → D7 · Echo → D6

Rango: 2–450 cm

Uso: Obstáculos, nivel de agua, alarma proximidad

// Lectura rápida
long duracion, distancia;
digitalWrite(trig, LOW);
delayMicroseconds(2);
digitalWrite(trig, HIGH);
delayMicroseconds(10);
digitalWrite(trig, LOW);
duracion = pulseIn(echo, HIGH);
distancia = duracion * 0.034 / 2;

🌡️ DHT11 — Temp. y Humedad

VCC → 5V · GND → GND · DATA → D2

DHT11: 0–50°C / 20–90% HR

Uso: Estación meteorológica, ventilación automática

// Con librería DHT
float t = dht.readTemperature();
float h = dht.readHumidity();
Serial.print("Temp: "); Serial.print(t);
Serial.print("°C | Humedad: "); Serial.print(h); Serial.println("%");

👁️ PIR — Movimiento

VCC → 5V · GND → GND · OUT → D2

Detecta cambios de radiación infrarroja

Uso: Luces automáticas, alarma, ahorro energético

int lectura = digitalRead(pirPin);
if (lectura == HIGH) {
  Serial.println("¡Movimiento detectado!");
  digitalWrite(led, HIGH);
} else {
  digitalWrite(led, LOW);
}

💡 LDR — Nivel de Luz

LDR + Resistencia → Divisor de tensión → A0

Valor alto = poca luz · Valor bajo = mucha luz

Uso: Encendido automático, cortinas solares

int luz = analogRead(ldrPin);
if (luz > 600) {
  digitalWrite(led, HIGH); // Está oscuro → encender
} else {
  digitalWrite(led, LOW);  // Hay luz → apagar
}

🌱 Maceta Inteligente — Riego Automático

🔌 Conexiones

Componente Pin Arduino
Sensor Humedad VCC5V 🔴
Sensor Humedad GNDGND ⚫
Sensor Humedad AOA0 🟢
Relé VCC5V 🔴
Relé GNDGND ⚫
Relé IND7 🟡
Relé COM → Bomba +—
Relé NO → Fuente +—
Bomba −GND ⚫

⚠️ La bomba necesita su propia fuente de alimentación externa. Nunca conectarla directamente a los pines del Arduino.

💻 Código Completo

/*
  MACETA INTELIGENTE — Riego Automático
  Placa: Arduino Uno
*/

const int pinHumedad = A0;
const int pinRele = 7;

// Calibra estos valores con tu sensor
const int SECO  = 350;  // Encender si supera
const int HUMEDO = 200; // Apagar si baja

int estadoBomba = LOW;
int valorSensor = 0;

void setup() {
  pinMode(pinRele, OUTPUT);
  digitalWrite(pinRele, LOW);
  Serial.begin(9600);
  Serial.println("=== SISTEMA DE RIEGO INICIADO ===");
}

void loop() {
  valorSensor = analogRead(pinHumedad);
  
  Serial.print("Valor: ");
  Serial.print(valorSensor);

  if (valorSensor > SECO && estadoBomba == LOW) {
    estadoBomba = HIGH;
    digitalWrite(pinRele, HIGH);
    Serial.println(" → 🌵 SECO — ENCENDIENDO BOMBA");
  } 
  else if (valorSensor < HUMEDO && estadoBomba == HIGH) {
    estadoBomba = LOW;
    digitalWrite(pinRele, LOW);
    Serial.println(" → 💧 HÚMEDO — APAGANDO BOMBA");
  }
  else {
    Serial.println(" → OK");
  }

  delay(2000); // Esperar 2 segundos
}

📐 Calibración Paso a Paso

  1. Conecta todo sin la bomba aún
  2. Abre el Monitor Serie a 9600 baudios
  3. Con el sensor al aire → anota el valor → ese es tu SECO
  4. Con el sensor en agua/tierra húmeda → anota → ese es tu HUMEDO
  5. Modifica el código con tus valores y vuelve a cargar
  6. Agrega al menos 50 puntos de diferencia entre ambos para estabilidad

🧱 Código por Bloques

AL INICIAR
  Establecer pin 7 como SALIDA
  Escribir pin 7 → BAJO
  Iniciar serie a 9600
  UMBRAL_SECO = 350
  UMBRAL_HUMEDO = 200
  estadoBomba = BAJO

POR SIEMPRE
  valor = leer A0
  Enviar por serie "Valor: " + valor

  SI valor > UMBRAL_SECO Y estadoBomba = BAJO:
    escribir pin 7 → ALTO
    estadoBomba = ALTO
    enviar " → BOMBA ENCENDIDA 💧"
  SI NO SI valor < UMBRAL_HUMEDO Y estadoBomba = ALTO:
    escribir pin 7 → BAJO
    estadoBomba = BAJO
    enviar " → BOMBA
    enviar " → BOMBA APAGADA ✅"
  FIN SI

  Esperar 2000 milisegundos

🧪 Cómo Probar

  1. Arrastra todos los componentes al área de trabajo
  2. Conecta siguiendo la tabla anterior
  3. Ve a la pestaña Código → Bloques
  4. Arma el diagrama tal como se muestra arriba
  5. Pulsa ▶ Iniciar simulación
  6. Haz clic sobre el sensor → mueve el control deslizante:
    • Hacia seco → valor sube → motor gira 💧
    • Hacia húmedo → valor baja → motor se detiene ✅
  7. Abre el Monitor Serie para ver los valores en tiempo real

🔄 De la Simulación a la Vida Real

En Tinkercad

  • Motor DC visual → Bomba de agua real
  • Control deslizante → Sensor enterrado en la tierra
  • Alimentación simplificada → Fuente externa para la bomba

En la realidad

  • ⚠️ Nunca conectar la bomba directamente a los pines del Arduino
  • Usar siempre el relé como intermediario
  • Limpiar las puntas del sensor cada 2 semanas
  • No dejar la bomba funcionando sin agua

💡 Variantes para Ampliar el Proyecto

⚠️ Normas de Seguridad

Antes de conectar

  • • Verifica que no haya cables sueltos o cruzados
  • • Confirma polaridad: VCC → nunca a GND
  • • Desconecta el USB antes de modificar conexiones

Al trabajar

  • • Solo usar 5V o 3.3V — nunca corriente de red
  • • La bomba siempre con fuente propia + relé
  • • No tocar componentes con la mano húmeda
