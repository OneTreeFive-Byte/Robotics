🤖 Arduino Uno

Placa de hardware libre basada en el microcontrolador ATmega328p. Estándar mundial educativo.

  • ▸ 14 pines digitales (6 con PWM)
  • ▸ 6 entradas analógicas
  • ▸ Alimentación: 5V / 3.3V
  • ▸ Comunicación: USB, I2C, SPI
  • ▸ Lenguaje: C/C++ simplificado

// MÓDULOS Y SENSORES センサー

Sensor Ultrasonido HC-SR04

Emite un pulso ultrasónico y calcula el tiempo que tarda en rebotar para determinar la distancia exacta a un objeto.

Fotorresistencia (LDR)

Varía su resistencia eléctrica en función de la luz ambiental. Ideal para activar luces automáticas al oscurecer.

Humedad de Suelo

Detecta la conductividad de la tierra. A mayor humedad, menor resistencia y mayor voltaje en la salida analógica.

// PROYECTO: MACETA INTELIGENTE プロジェクト

🌿 Descripción del Sistema

Este proyecto automatiza el riego de una planta utilizando un Arduino Uno, un sensor de humedad de tierra y un módulo de relé que controla una mini bomba de agua. Cuando la tierra se seca, el sistema activa la bomba de manera autónoma.

Componentes necesarios:
  • Placa Arduino Uno + Cable USB
  • Sensor de humedad de suelo
  • Módulo Relé de 1 canal (5V)
  • Mini bomba de agua sumergible (5V)
  • Protoboard y cables de conexión
  • Fuente de alimentación externa para la bomba
Lógica de Funcionamiento:
  1. Lee el valor analógico del sensor de suelo constantemente.
  2. Si el valor es inferior al umbral seco, activa el relé.
  3. El relé enciende la bomba durante unos segundos.
  4. Muestra el estado actual en el Monitor Serial de Arduino.

Código C++ (Arduino IDE)

maceta_inteligente.ino 
const int sensorPin = A0; // Pin analógico del sensor de humedad
const int relePin = 8;    // Pin digital conectado al módulo relé
const int umbralSeco = 500; // Valor límite para considerar la tierra seca

void setup() {
  pinMode(relePin, OUTPUT);
  digitalWrite(relePin, HIGH); // Apagar relé al iniciar (Lógica inversa común en relés)
  Serial.begin(9600);
  Serial.println("Sistema de Maceta Inteligente Iniciado...");
}

void loop() {
  int humedad = analogRead(sensorPin);
  Serial.print("Humedad actual: ");
  Serial.println(humedad);

  if (humedad > umbralSeco) {
    Serial.println("¡Tierra seca! Activando riego...");
    digitalWrite(relePin, LOW);  // Enciende la bomba
    delay(3000);                 // Riega durante 3 segundos
    digitalWrite(relePin, HIGH); // Apaga la bomba
    delay(5000);                 // Espera 5 segundos antes de volver a medir
  } else {
    Serial.println("La tierra tiene buena humedad.");
    digitalWrite(relePin, HIGH); // Asegura que la bomba esté apagada
  }
  
  delay(2000); // Espera 2 segundos entre lecturas
}

¿Cómo simular circuitos en la nube?

Tinkercad Circuits de Autodesk te permite diseñar y probar código y conexiones sin necesidad de tener el hardware físico en tus manos.

  1. Ingresa a tinkercad.com y crea una cuenta gratuita.
  2. Dirígete a la sección Circuitos y haz clic en Crear nuevo circuito.
  3. Busca en la barra lateral derecha componentes como Arduino Uno R3, Protoboard y LEDs o Sensores.
  4. Conecta los cables haciendo clic entre los terminales.
  5. Haz clic en el botón Código para escribir o arrastrar bloques de programación y presiona Iniciar simulación.
